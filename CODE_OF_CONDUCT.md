# Code of Conduct

We want this project to be a welcoming, harassment-free experience for everyone.

## Our standards

- Be respectful and constructive
- Assume good intent; give thoughtful feedback
- No harassment, hate speech, or discrimination
- No unwanted sexual attention or sexualized language

## Scope

This applies to all project spaces (issues, pull requests, discussions, and any other communication related to this repository).

## Enforcement

If you experience or witness unacceptable behavior, please contact the maintainers privately.
Maintainers may remove, edit, or reject contributions that violate this code of conduct.
